Importance describes how the fitted Random Forest used input features. It does not prove that changing a feature will cause a grade to change.

How to read the scores

Three useful evaluation measures

MAE
Mean Absolute Error

Average absolute difference between predicted and actual grades. Lower is better.

RMSE
Root Mean Squared Error

Penalizes larger prediction errors more heavily. Lower is better.

R²
Coefficient of Determination

Shows how well predictions explain target variation on the test split. Near 1 is stronger; it can be negative.

ABOUT THE PROJECT

A practical ML workflow,
from Colab to the web.

This website follows the provided Colab notebook: it uses the UCI Student Performance mathematics dataset, selects age, studytime, failures, absences, G1 and G2, trains Linear Regression and Random Forest Regression, and evaluates them using MAE, RMSE and R².

The underlying dataset describes students at two Portuguese schools. G1 and G2 are prior-period grades, and G3 is the final-grade target. Results may not generalize to different schools, curricula or student populations.
