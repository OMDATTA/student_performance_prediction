# Dataset

The Colab notebook uses the UCI Student Performance dataset, file `student-mat.csv`,
loaded from the original UCI ZIP URL. The server can use a local copy if you add
`data/student-mat.csv` (semicolon-separated); otherwise it tries UCI and documented
public mirrors on the first prediction/metrics request.

Dataset page: https://archive.ics.uci.edu/dataset/320/student%2Bperformance
Please retain dataset attribution if you redistribute the dataset itself.
