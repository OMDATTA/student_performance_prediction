# Notebooks

- `student_performance_prediction.ipynb`: copy of the notebook provided for this project.
- `student_performance_prediction_web_deploy.ipynb`: the provided notebook with an additional final cell that exports both trained models, metrics, and feature-importance data to `student_performance_models.joblib` for use by the Vercel API.

Open the deployment copy in Google Colab and run all cells top-to-bottom to create the artifact.
